# Aleph Next

An open-source geospatial exploration and data processing platform.

Aleph Next provides an interactive environment for geographical
data collection, processing, visualization and AI-assisted analysis.

## Technology Stack

### Frontend
- Next.js
- TypeScript
- Tailwind CSS
- MapLibre GL JS
- Three.js

### Backend
- Python
- FastAPI
- PostgreSQL
- PostGIS
- Redis
- Celery

### AI
- LLM Integration
- Model Context Protocol (MCP)

### Infrastructure
- Docker
- Docker Compose
- AWS

## Project Structure

- frontend/       Web application
- backend/        REST API and processing engine
- cli/            Command-line interface
- infrastructure/ Deployment and infrastructure
- docs/           Technical documentation
- data/           Local generated datasets
